# Bundled UI fonts

- **JetBrains Mono** (Regular, Medium, Bold), version 2.304, from the [JetBrains Mono repository](https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/webfonts). Licensed under the SIL Open Font License 1.1; see [OFL.txt](./OFL.txt).
- **Anakotmai** (Light, Medium, Bold), from [Thai Web Fonts, version 7](https://github.com/lazywasabi/thai-web-fonts/tree/7/fonts/Anakotmai). The [font listing](https://thaiwebfonts.pages.dev/fonts/anakotmai/) credits the Future Forward Party and lists its license as public domain (archived).

These WOFF2 files are served locally by Next.js. Latin characters use JetBrains Mono, while Thai characters fall back to Anakotmai.
